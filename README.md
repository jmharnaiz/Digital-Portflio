# John Mike Harnaiz Portfolio

A personal portfolio website built with plain HTML, CSS, and JavaScript.

## Project Structure

- `index.html` — main portfolio page
- `assets/css/style.css` — styling
- `assets/js/script.js` — project modal and interactive logic
- `assets/cv/John-Mike-Harnaiz-CV.html` — downloadable CV page
- `Harnaiz.jpeg` — profile image

## Local Preview

Open `index.html` in your browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. Go to https://vercel.com
3. Click "Add New Project"
4. Import the GitHub repository
5. Keep the default settings and click "Deploy"

Vercel will automatically detect the static site and publish it.

## Notes

This project is static and does not require a build step for deployment.
